# AWS Research

## Brief Overview

**Amazon Web Services (AWS)** is a cloud computing platform that provides a wide range of on-demand cloud services. It allows organizations to access computing, storage, databases, networking, and other technologies through the internet.

---

## Global Infrastructure

AWS operates a global cloud infrastructure made up of **Regions** and **Availability Zones**.

* **Regions** are separate geographic areas where AWS provides cloud infrastructure.
* **Availability Zones** are isolated locations within an AWS Region that provide additional reliability and availability.

This infrastructure helps organizations build applications with **high availability, reliability, and scalability**.

---

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services.

Through the console, users can:

* Create cloud resources.
* Configure services.
* Monitor resources.
* Manage applications and infrastructure.
* Access different AWS services.

---

# Four Core AWS Services

## 1. Amazon EC2

**Amazon Elastic Compute Cloud (EC2)** provides virtual servers that can be used to run applications and workloads in the cloud.

**Common uses:**

* Web hosting
* Application hosting
* Development environments
* Running Linux or Windows servers

---

## 2. Amazon S3

**Amazon Simple Storage Service (S3)** provides scalable object storage for files, data, backups, and other digital objects.

**Common uses:**

* File storage
* Data backups
* Static website content
* Data archiving

---

## 3. Amazon RDS

**Amazon Relational Database Service (RDS)** provides managed relational databases. It makes it easier to set up, operate, and scale databases without managing the underlying database infrastructure manually.

**Common uses:**

* Web application databases
* Business applications
* Data management
* Database development and testing

---

## 4. Amazon VPC

**Amazon Virtual Private Cloud (VPC)** allows organizations to create an isolated virtual network for their AWS resources.

**Common uses:**

* Network configuration
* Security
* Connecting cloud resources
* Controlling network access

---

# Three Advantages of AWS

### 1. Scalability

AWS allows organizations to **increase or decrease resources** based on their requirements. This helps businesses handle changes in workload and demand.

### 2. Global Infrastructure

AWS provides cloud infrastructure across multiple **geographic locations worldwide**, allowing organizations to deploy applications closer to their users.

### 3. Wide Range of Services

AWS offers a large selection of services for **computing, storage, databases, networking, security, analytics, and other business requirements**.

---

# Typical Enterprise Use Cases

AWS can be used by enterprises for various business and technical requirements, including:

* **Web application hosting**
* **Data storage and backup**
* **Database management**
* **Application development**
* **Data analytics**
* **Scalable business applications**

# Summary

AWS provides a comprehensive cloud computing platform with services for computing, storage, databases, networking, and many other business needs. Services such as **EC2, S3, RDS, and VPC** provide organizations with flexible and scalable tools for building and managing cloud-based applications and infrastructure.
