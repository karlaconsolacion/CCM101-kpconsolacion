# 2. Questions and Answers

## 2.1 Which cloud provider offers the broadest range of services?

**AWS** offers a very broad range of cloud services covering **computing, storage, databases, networking, security, analytics, and other areas**.

This makes AWS suitable for organizations with many different cloud requirements.

---

## 2.2 Which provider best integrates with Microsoft technologies?

**Microsoft Azure** provides the strongest integration with Microsoft technologies.

It is especially suitable for organizations already using technologies such as:

* Windows Server
* Microsoft 365
* Active Directory
* Other Microsoft enterprise solutions

---

## 2.3 Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform (GCP)** is particularly strong in **Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes**.

Its cloud services are well suited for organizations developing AI applications, machine learning solutions, and cloud-native workloads.

---

## 2.4 Which cloud platform would you personally choose and why?

I would personally choose **AWS** because it provides a broad selection of cloud services and can support different types of applications and business requirements.

Its wide range of services also provides many opportunities for **learning, experimentation, and developing cloud computing skills**.

---

# 3. Overall Comparison

Each cloud platform has different strengths and is suitable for different organizational needs.

* **AWS** is a strong choice for organizations that need a broad range of cloud services and flexible infrastructure.
* **Microsoft Azure** is well suited for organizations that rely heavily on Microsoft technologies and enterprise solutions.
* **Google Cloud Platform** is a strong choice for organizations focused on AI, machine learning, data analytics, Kubernetes, and cloud-native applications.

Overall, the best cloud platform depends on the **organization's requirements, existing technologies, budget, technical expertise, and business goals**.
