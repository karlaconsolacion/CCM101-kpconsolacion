# Reflection

This laboratory activity helped me gain a better understanding of working with a cloud-based Linux environment.
I learned how to use basic Linux commands, create and manage user accounts, navigate directories, and check 
important system information. These activities gave me practical experience with Linux and helped me become 
more comfortable working in a cloud environment.

helped me understand the importance of keeping technical files and documentation organized. It also taught me how to
manage and update my work properly so that it is easier to access and review.

Overall, this activity improved my basic knowledge and skills in Linux and cloud computing. More importantly, it gave
me hands-on experience that I can apply to future laboratory activities and other cloud-related tasks. I believe the
skills I learned from this laboratory will be useful as I continue developing my knowledge in
cloud computing and information technology.
