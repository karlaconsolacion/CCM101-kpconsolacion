# Reflection

## What I Learned

In this laboratory activity, I learned how to access and navigate a Linux cloud environment using KillerCoda. I practiced basic Linux commands and learned how to check system information such as the username, hostname, operating system, kernel, CPU, memory, and disk space.

## Challenges Encountered

One of the challenges I encountered was creating and managing files and directories in the Linux terminal. I also experienced difficulty understanding the correct file paths and commands. Through repeated practice, I learned how to properly navigate directories and create Markdown files.

## GitHub Experience

I also learned how to create and manage a GitHub repository. I learned how to organize laboratory files, create Markdown documentation, and connect a Linux environment to GitHub using Git.

## Overall Reflection

This activity helped me understand the importance of Linux, cloud environments, documentation, and version control. The experience gave me a better understanding of the basic skills needed for cloud computing and system administration.
